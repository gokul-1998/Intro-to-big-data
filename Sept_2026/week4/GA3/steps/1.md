# GA3 — Click Counts by Time-of-Day Bins (PySpark on Dataproc)

## What the script does

[ga3_click_counts.py](file:///d:/gokul_repos/iitm/Intro-to-big-data/Sept_2026/week4/GA3/ga3_click_counts.py) reads a CSV with `user_id, timestamp` columns and counts clicks in 4 time bins:

| Bin | Hours |
|-----|-------|
| 0-6 | Midnight → 6 AM |
| 6-12 | 6 AM → Noon |
| 12-18 | Noon → 6 PM |
| 18-24 | 6 PM → Midnight |

It implements **both** approaches (no SparkSQL):
1. **RDD** — `map` → extract hour → `(bin, 1)` → `reduceByKey`
2. **DataFrame** — `hour()` + `when()` → `groupBy` → `agg(count)`

## Step-by-step GCP instructions

### 1. Download the input file

Download from the Google Drive link in the assignment:
> https://drive.google.com/file/d/1r7EJBcVFpvQLSbsJ3fTcWWlW5OB6m51k/view

### 2. Create a GCS bucket (if you don't have one)

```bash
gsutil mb -l asia-south1 gs://gokul-s-iitm-bucket/
```

### 3. Upload the input file to GCS

```bash
gsutil cp clicks.txt gs://gokul-s-iitm-bucket/input/clicks.txt
```

### 4. Create the Dataproc cluster (without the bucket flag)

Since you said you create the cluster **without the bucket**, use:

```bash
gcloud dataproc clusters create gokul-s-dataproc-cluster \
  --project project-77971f5c-a874-479a-a6c \
  --region asia-south1 \
  --single-node \
  --master-machine-type e2-standard-2 \
  --master-boot-disk-size 50GB \
  --max-idle 60m \
  --optional-components JUPYTER
```

> [!NOTE]
> Without `--bucket`, Dataproc creates its own staging bucket. You'll still use **your** bucket for input/output paths.

### 5. Upload the PySpark script to GCS

```bash
gsutil cp ga3_click_counts.py gs://gokul-s-iitm-bucket/scripts/ga3_click_counts.py
```

### 6. Submit the job to Dataproc

```bash
gcloud dataproc jobs submit pyspark \
  gs://ibd_bucket_gokul/week_4/ga3_click_counts.py \
  --cluster=gokul-s-dataproc-cluster \
  --region=asia-south1 \
  --project=project-77971f5c-a874-479a-a6c \
  -- gs://ibd_bucket_gokul/week_4/click_file.txt gs://ibd_bucket_gokul/week_4/output
```

> [!IMPORTANT]
> The `--` separates `gcloud` flags from script arguments. After `--`, the two args are **input path** and **output path**.

### 7. Download the output

```bash
# RDD output (part files)
gsutil cp -r gs://gokul-s-iitm-bucket/output/rdd_output/ ./rdd_output/

# DataFrame output (CSV with header)
gsutil cp -r gs://gokul-s-iitm-bucket/output/df_output/ ./df_output/
```

### 8. Clean up (delete cluster when done)

```bash
gcloud dataproc clusters delete gokul-s-dataproc-cluster \
  --region=asia-south1 \
  --project=project-77971f5c-a874-479a-a6c
```
