## GA6: Google Cloud Dataproc + SparkSQL + SCD

### 🗺️ Overview of Steps

```
1. GCP Setup (Dataproc Cluster + GCS Bucket)
2. Download & Upload Datasets to GCS
3. Write SparkSQL Aggregation Queries
4. Implement SCD Type I & Type II
5. Save outputs to GCS + Submit
```

---

### Step 1 — GCP Setup

1. **Create a GCS Bucket** (e.g., `gs://your-bucket-name/`)
2. **Create a Dataproc Cluster**:
   - Go to Dataproc → Create Cluster → Single Node is fine for this
   - Region: `us-central1` (or your preferred)
3. **Upload datasets** from the [Drive link](https://drive.google.com/drive/folders/1d1QPXN0Vi9XEaq74g16rUXAylKQjfNIf) to GCS:
   ```
   gsutil cp transactions.csv gs://your-bucket/input/
   gsutil cp customer_master.csv gs://your-bucket/input/
   gsutil cp customer_updates.csv gs://your-bucket/input/
   ```

### Step 2 — Aggregation Queries (SparkSQL)

Your `.py` file will look like:

```python
from pyspark.sql import SparkSession

spark = SparkSession.builder.appName("GA6").getOrCreate()

# Load data
transactions = spark.read.csv("gs://your-bucket/input/transactions.csv", header=True, inferSchema=True)
transactions.createOrReplaceTempView("transactions")

# Q1: Top 5 customers by total transaction amount
top5 = spark.sql("""
    SELECT customer_id, SUM(amount) as total_amount
    FROM transactions
    GROUP BY customer_id
    ORDER BY total_amount DESC
    LIMIT 5
""")
top5.show()
top5.coalesce(1).write.csv("gs://your-bucket/output/top5_customers", header=True)

# Q2: Number of customers per city
per_city = spark.sql("""
    SELECT city, COUNT(DISTINCT customer_id) as num_customers
    FROM transactions
    GROUP BY city
""")
per_city.show()
per_city.coalesce(1).write.csv("gs://your-bucket/output/customers_per_city", header=True)

# Q3: Average transaction value overall
avg_val = spark.sql("""
    SELECT AVG(amount) as avg_transaction_value
    FROM transactions
""")
avg_val.show()
avg_val.coalesce(1).write.csv("gs://your-bucket/output/avg_transaction", header=True)
```

> [!NOTE] You'll need to adjust column names (`customer_id`, `amount`, `city`) after checking the actual dataset schema.

### Step 3 — SCD Type I (Overwrite / No History)

```python
customer = spark.read.csv("gs://your-bucket/input/customer_master.csv", header=True, inferSchema=True)
updates = spark.read.csv("gs://your-bucket/input/customer_updates.csv", header=True, inferSchema=True)

customer.createOrReplaceTempView("customer_master")
updates.createOrReplaceTempView("customer_updates")

print("=== BEFORE SCD Type I ===")
spark.sql("SELECT * FROM customer_master").show()

# SCD Type I: Overwrite changed fields
scd1 = spark.sql("""
    SELECT
        COALESCE(u.customer_id, c.customer_id) AS customer_id,
        COALESCE(u.name, c.name) AS name,
        COALESCE(u.city, c.city) AS city,
        COALESCE(u.email, c.email) AS email
    FROM customer_master c
    LEFT JOIN customer_updates u ON c.customer_id = u.customer_id
""")
scd1.createOrReplaceTempView("customer_scd1")
print("=== AFTER SCD Type I ===")
scd1.show()
scd1.coalesce(1).write.csv("gs://your-bucket/output/scd1_result", header=True)
```

### Step 4 — SCD Type II (Preserve History with versioning)

```python
from pyspark.sql.functions import lit, current_date

print("=== BEFORE SCD Type II ===")
spark.sql("SELECT * FROM customer_master").show()

# Mark old records as inactive, add new records as active
old_records = spark.sql("""
    SELECT c.*, 'N' as is_current
    FROM customer_master c
    JOIN customer_updates u ON c.customer_id = u.customer_id
""")

new_records = spark.sql("""
    SELECT u.customer_id, u.name, u.city, u.email, 'Y' as is_current
    FROM customer_updates u
""")

unchanged = spark.sql("""
    SELECT c.*, 'Y' as is_current
    FROM customer_master c
    LEFT JOIN customer_updates u ON c.customer_id = u.customer_id
    WHERE u.customer_id IS NULL
""")

scd2 = old_records.union(new_records).union(unchanged)
print("=== AFTER SCD Type II ===")
scd2.show()
scd2.coalesce(1).write.csv("gs://your-bucket/output/scd2_result", header=True)
```

### Step 5 — Submit the Job on Dataproc

1. Upload your `.py` file to GCS:
   ```
   gsutil cp ga6.py gs://your-bucket/scripts/
   ```
2. Submit via console or CLI:
   ```
   gcloud dataproc jobs submit pyspark gs://your-bucket/scripts/ga6.py \
     --cluster=your-cluster-name \
     --region=us-central1
   ```
3. **Screenshot** the Dataproc job details page showing "Succeeded"
