Ran command: `gcloud --version`

Google Cloud now enforces the **`iam.disableServiceAccountKeyCreation`** policy by default to prevent downloading private JSON key files to local machines.

Here are the best ways to proceed:

---

### Method 1: Run it in GCP Cloud Shell or Compute Engine VM (Easiest & Assignment Requirement)

Your assignment states:
> *"Spin Up a VM and run the program from your VM."*

In GCP, Compute Engine VMs and Cloud Shell **do not require JSON keys**. Authentication happens automatically via IAM metadata:

1. **Option A: GCP Cloud Shell (Immediate, No Setup)**:
   - In Google Cloud Console, click the **Activate Cloud Shell** icon (`>_`) in the top-right navbar.
   - Upload your `1.py` and `input.txt` (click the three dots `⋮` > **Upload**).
   - Run:
     ```bash
     pip install google-cloud-storage
     python3 1.py
     ```
   - It will authenticate automatically using your Google login!

2. **Option B: On your Compute Engine VM**:
   - When creating or editing your VM, under **Identity and API access**:
     - Ensure the default service account is selected.
     - Under **Access scopes**, choose **Allow full access to all Cloud APIs** (or enable **Storage: Read/Write**).
   - SSH into the VM: Python scripts running on that VM can upload/download from GCS directly without any key files.

---

### Method 2: If you just need the file uploaded to the bucket right now

If your goal right now is simply to get `input.txt` into `ibd_bucket_gokul`:
1. Go to **Cloud Storage** > **Buckets** > `ibd_bucket_gokul` in the GCP Console.
2. Click **Upload Files** and select `input.txt`.
3. (Optional) Rename it to `wk_1_input.txt` in the console.

---

### Method 3: Authenticate Locally via `gcloud` CLI (Application Default Credentials)

Google's recommended way for local development without JSON keys:

1. **Install Google Cloud SDK for Windows**:
   - Download the installer from: [cloud.google.com/sdk/docs/install#windows](https://cloud.google.com/sdk/docs/install#windows)
   - Or install via PowerShell:
     ```powershell
     winget install Google.CloudSDK
     ```
2. **Log in once via browser**:
   ```powershell
   gcloud auth application-default login
   ```
3. A browser tab will open asking you to log in with your Google account. Once approved, `google.cloud.storage` in `1.py` will automatically work without any environment variable or JSON file.

---

### Method 4: Disable the Organization Policy (If you are the Project/Org Admin)

If this is your personal GCP account / you own the Google Cloud organization:
1. In GCP Console, search for **Organization Policies** in the top search bar.
2. Search for the constraint: `iam.disableServiceAccountKeyCreation` (**Disable service account key creation**).
3. Click on it and select **Manage Policy** / **Edit**.
4. Change policy enforcement to **Off** (or set rule to **Not Enforced**), then click **Save**.
5. Return to **Service Accounts** > **Keys** > **Create new key** (JSON creation will now be allowed).

*(Note: If you are using a university/institutional Google Workspace account like `@study.iitm.ac.in`, only the IITM IT admins can change this policy, so **Method 1** or **Method 3** is the way to go).*
