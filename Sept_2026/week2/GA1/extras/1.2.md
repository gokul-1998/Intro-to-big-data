To get and configure the **`GOOGLE_APPLICATION_CREDENTIALS`** key file, you have three options depending on your setup:

---

### Option 1: Generate a Service Account JSON Key from GCP Console (Recommended for local dev)

1. **Go to Google Cloud Console**:
   - Open [console.cloud.google.com](https://console.cloud.google.com) and make sure your project (where `ibd_bucket_gokul` exists) is selected in the top bar.

2. **Navigate to Service Accounts**:
   - In the search bar or left navigation menu, go to **IAM & Admin** > **Service Accounts**.

3. **Create a Service Account**:
   - Click **+ Create Service Account** at the top.
   - Enter a name (e.g. `gcs-uploader` or `bda-assignment`).
   - Click **Create and Continue**.
   - Under **Grant this service account access to project**, select role:
     - **Storage Object Admin** (allows reading/writing objects to buckets).
   - Click **Continue**, then click **Done**.

4. **Create and Download the JSON Key**:
   - Find your new service account in the list and click on its email address.
   - Open the **Keys** tab at the top.
   - Click **Add Key** > **Create new key**.
   - Choose **JSON** and click **Create**.
   - A `.json` file will automatically download to your computer.

5. **Set the Environment Variable**:
   Save the file somewhere safe (e.g. `D:\gcp_keys\my-key.json`).

   > [!WARNING]
   > Never commit this `.json` key file to a Git repository. Add `*.json` to your `.gitignore`.

   In **PowerShell** (your current terminal):
   ```powershell
   $env:GOOGLE_APPLICATION_CREDENTIALS="D:\path\to\your-key.json"
   ```

   To test and run your script:
   ```powershell
   py .\1.py
   ```

   *(To make the environment variable permanent on Windows, search for "Environment Variables" in Windows Start menu and add `GOOGLE_APPLICATION_CREDENTIALS` under User variables).*

---

### Option 2: Use `gcloud` CLI (No JSON key needed locally)

If you have Google Cloud SDK (`gcloud`) installed on Windows, you don't need a JSON key file at all:

1. Run:
   ```powershell
   gcloud auth application-default login
   ```
2. A browser window will open. Sign in to your Google account that owns the GCP project.
3. Once authenticated, Google Cloud SDK stores credentials automatically, and Python's `google.cloud.storage` will detect them without needing any environment variable.

---

### Option 3: If running inside a GCP Compute Engine VM

Since your assignment mentions:
> *- Spin Up a VM and run the program from your VM.*

When you run this script on a **GCP Compute Engine VM**, you **do not** need a JSON key:
- When creating the VM, ensure under **Identity and API access** > **Access scopes** that you allow **Full access to all Cloud APIs** or enable **Storage: Read/Write**.
- The script on the VM automatically inherits the VM's service account permissions without needing `GOOGLE_APPLICATION_CREDENTIALS`.
