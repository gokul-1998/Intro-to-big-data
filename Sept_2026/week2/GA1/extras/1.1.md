### Prerequisites

Ensure the Google Cloud Storage library is installed:
```bash
pip install google-cloud-storage
```

Ensure authentication is configured either via:
- Google Cloud VM default service account permissions, or
- `gcloud auth application-default login`, or
- Setting `GOOGLE_APPLICATION_CREDENTIALS=/path/to/key.json`.

---

### Usage

Run with command-line arguments:
```bash
python 1.py --bucket <your-bucket-name> --source <path-to-file> --destination <destination-blob-name>
```

Or import the `upload_to_gcs` function in another script:
```python
from extras.1 import upload_to_gcs

upload_to_gcs(
    bucket_name="your-bucket-name",
    source_file_path="input.txt",
    destination_blob_name="input.txt"
)
```
