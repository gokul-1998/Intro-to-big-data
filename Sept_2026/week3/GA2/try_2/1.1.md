Searched "Permission storage.buckets.get denied" "Eventarc" "gcloud functions deploy"

This error happened because **`eventarc.googleapis.com` was just enabled for the first time**, which means the Google-managed **Eventarc Service Agent** was newly created and does not have permission to inspect or read the GCS bucket yet.

Run the following commands in your Cloud Shell to grant the required permissions:

---

### Step 1: Verify the Bucket Exists in This Project

Check that `gokul_ibd_bucket` exists in `project-c38127c2-5130-4284-af3`:
```bash
gcloud storage buckets describe gs://gokul_ibd_bucket
```
*(If it gives a 404 Not Found error, create it with: `gcloud storage buckets create gs://gokul_ibd_bucket --location=us`)*

---

### Step 2: Grant the Required Service Agent Permissions

Copy and paste these commands into Cloud Shell:

```bash
PROJECT_ID=$(gcloud config get-value project)
PROJECT_NUMBER=$(gcloud projects describe $PROJECT_ID --format="value(projectNumber)")

# 1. Grant Eventarc Service Agent permissions to inspect the bucket
gcloud projects add-iam-policy-binding $PROJECT_ID \
  --member="serviceAccount:service-${PROJECT_NUMBER}@gcp-sa-eventarc.iam.gserviceaccount.com" \
  --role="roles/eventarc.serviceAgent"

gcloud projects add-iam-policy-binding $PROJECT_ID \
  --member="serviceAccount:service-${PROJECT_NUMBER}@gcp-sa-eventarc.iam.gserviceaccount.com" \
  --role="roles/storage.admin"

# 2. Grant Cloud Storage service agent permission to publish GCS events
gcloud projects add-iam-policy-binding $PROJECT_ID \
  --member="serviceAccount:service-${PROJECT_NUMBER}@gs-project-accounts.iam.gserviceaccount.com" \
  --role="roles/pubsub.publisher"

# 3. Grant Compute Engine service account permission to receive events
gcloud projects add-iam-policy-binding $PROJECT_ID \
  --member="serviceAccount:${PROJECT_NUMBER}-compute@developer.gserviceaccount.com" \
  --role="roles/eventarc.eventReceiver"
```
