The issue is identified in the bucket details:

```yaml
location: US-EAST1
location_type: region
name: gokul_ibd_bucket
```

Your bucket is in **`us-east1`**, but your deploy command specified `--trigger-location us` (multi-region). Eventarc looked for the bucket in the `us` multi-region and could not find it.

Your IAM roles are now fully bound and ready. Simply run the deploy command with **`--trigger-location us-east1`**:

```bash
gcloud functions deploy process_file \
  --gen2 \
  --runtime python312 \
  --region us-east1 \
  --source . \
  --entry-point process_file \
  --trigger-location us-east1 \
  --trigger-event-filters="type=google.cloud.storage.object.v1.finalized" \
  --trigger-event-filters="bucket=gokul_ibd_bucket" \
  --allow-unauthenticated
```

*(Both the function `--region` and `--trigger-location` are set to `us-east1` to match your bucket).*
