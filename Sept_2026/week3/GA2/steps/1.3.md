Your bucket is in the `us` multi-region (visible in the screenshot), but you're deploying the function to `us-central1`. The trigger location must match the bucket location. Just change the region to `us`:

```bash
gcloud functions deploy process_file \
  --gen2 \
  --runtime python312 \
  --region us-central1 \
  --source . \
  --entry-point process_file \
  --trigger-location us \
  --trigger-event-filters="type=google.cloud.storage.object.v1.finalized" \
  --trigger-event-filters="bucket=ibd_bucket_gokul"
```

The key addition is `--trigger-location us` — this tells Eventarc to create the trigger in the `us` multi-region (matching your bucket), while the function itself still runs in `us-central1`.
