The trigger fires but can't invoke the function — the compute service account needs the Cloud Run invoker role. Run this:

```bash
gcloud functions add-invoker-policy-binding process_file \
  --region us-central1 \
  --member="serviceAccount:137496575726-compute@developer.gserviceaccount.com"
```

Then re-upload the file to trigger it again:

```bash
gcloud storage cp gs://ibd_bucket_gokul/wk_1_input.txt /tmp/test_input.txt
gcloud storage cp /tmp/test_input.txt gs://ibd_bucket_gokul/wk_1_input.txt
```

Wait ~30 seconds, then check logs:

```bash
gcloud functions logs read process_file --gen2 --region us-central1 --limit 50
```
