The error is because your Compute Engine VM doesn't have the right OAuth scopes to deploy Cloud Functions. Here are two ways to fix it:

### Option 1: Use `gcloud auth login` (Quickest)

Run this on your VM to authenticate with your own Google account instead of the VM's service account:

```bash
gcloud auth login --no-launch-browser
```

It will give you a URL — open it in your browser, sign in, paste the authorization code back into the terminal. Then re-run the deploy command.

### Option 2: Update the VM's access scopes (Permanent fix)

This requires **stopping the VM first**. From Cloud Shell or your local machine (not the VM itself):

```bash
# Stop the VM
gcloud compute instances stop instance-20261018-125917 --zone=YOUR_ZONE

# Update scopes to allow all APIs
gcloud compute instances set-service-account instance-20261018-125917 \
  --zone=YOUR_ZONE \
  --scopes=cloud-platform

# Restart the VM
gcloud compute instances start instance-20261018-125917 --zone=YOUR_ZONE
```

Then SSH back in and re-run the deploy command.

---

**I'd recommend Option 1** — it's faster and doesn't require restarting anything. Just run `gcloud auth login --no-launch-browser` on the VM.
