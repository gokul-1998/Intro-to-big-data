The Eventarc service account needs permission to read your GCS bucket. Run these commands:

### Step 1: Grant Eventarc's service agent access to the bucket

```bash
PROJECT_NUMBER=137496575726

# Grant Eventarc service agent the pubsub.publisher role (needed for GCS triggers)
gcloud projects add-iam-policy-binding project-77971f5c-a874-479a-a6c \
  --member="serviceAccount:service-${PROJECT_NUMBER}@gs-project-accounts.iam.gserviceaccount.com" \
  --role="roles/pubsub.publisher"

# Grant Eventarc service agent the eventarc.eventReceiver role
gcloud projects add-iam-policy-binding project-77971f5c-a874-479a-a6c \
  --member="serviceAccount:${PROJECT_NUMBER}-compute@developer.gserviceaccount.com" \
  --role="roles/eventarc.eventReceiver"
```

### Step 2: Re-deploy (wait ~1 min then run)

```bash
gcloud functions deploy process_file \
  --gen2 \
  --runtime python312 \
  --region us-central1 \
  --source . \
  --entry-point process_file \
  --trigger-event-filters="type=google.cloud.storage.object.v1.finalized" \
  --trigger-event-filters="bucket=ibd_bucket_gokul"
```

The GCS → Eventarc integration requires the Cloud Storage service account (`service-PROJECT_NUMBER@gs-project-accounts.iam.gserviceaccount.com`) to have Pub/Sub publisher permissions so it can notify Eventarc about new file uploads.
